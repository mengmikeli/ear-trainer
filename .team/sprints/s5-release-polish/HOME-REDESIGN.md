# Design Study: Home Page Redesign

## Brand
**LISSA** — the app name. Short for Lissajous. Also the training AI personality.

## Goal
Redesign the home page for Lissa. The P1 Lissajous ring is the brand mark. Chladni effects are the visual signature. Marathon "Graphic Realism" is the design language. Lissa is the AI voice.

## Status
Exploration — do NOT merge without Mike's explicit approval.

## Research areas

### Marathon visual language (deep study)
- Mosaic-style transition/loading effects
- Bold color block usage (not just dark + accent)
- Dot matrix / ASCII art as design elements
- Terminal boot sequences
- Equipment designation typography
- Designers Republic influence (Warp Records, Wipeout)
- HUD overlay patterns

### Lissajous as brand hero
- P1 ring as the central home page element
- Ring evolves with progression (P5 figure-8, etc.)
- Connection between the icon and the viz system

### References to study
- timeline.bumgie.org (Mike reference, 2026-04-01)
- Marathon reboot art direction
- Bungie.net original Marathon materials
- Designers Republic portfolio

## Constraints
- Must follow `.team/refs/VISUAL-IDENTITY.md`
- Current home page preserved under dev mode as functional fallback
- Mobile-first, responsive to desktop
- No emoji, no system fonts, Matrix Mono / BPdots / Maratype only
